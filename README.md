# AgentCrew — 多智能体工作方案制定系统

面向科研与课题工作的 **多 Agent 协作平台**。描述你的研究需求，由多个专业角色分工协作，自动完成课题规划、文献调研、实验设计、预算编制与方案终审，并在关键节点等待你审核把关。

适合：文献综述撰写、实验方案设计、完整科研工作方案制定。

---

## 核心特点

- **多角色协作** — 课题规划师、文献专家、实验设计师、预算分析师、终审专家分工配合，可按场景自由勾选参与角色
- **三种工作场景** — 文献综述、实验方案设计、完整工作方案，按需选择流程深度
- **人机协同** — 预算审批、方案终审等关键步骤自动暂停，你可审核输出、提出修改意见后再继续或终止
- **实时可见** — 工作流页面流式展示各 Agent 的输出与工具调用进度，运行中可中止、从中断处继续
- **参考文件支持** — 上传 txt / md / csv / json 作为背景资料，供规划与文献 Agent 参考（单文件最大 2MB）
- **历史方案管理** — 每次生成的方案自动命名标题，支持按标题或需求搜索，随时回看详情
- **一键导出** — 方案可导出为 Markdown 或 Word（`.docx`）
- **自定义 Agent** — 除内置角色外，可创建、编辑专属 Agent（含工具绑定与推理模式）
- **多用户隔离** — 注册登录后，历史方案与自定义 Agent 按用户独立存储

## 快速开始

### 1. 准备环境

```bash
git clone <your-repo-url>
cd AgentCrew

cp .env.example .env
```

编辑 `.env`，**至少填写**：

| 变量 | 说明 |
|------|------|
| `DEEPSEEK_API_KEY` | DeepSeek API 密钥（[获取地址](https://platform.deepseek.com/)） |
| `JWT_SECRET` | 登录令牌密钥，**生产环境务必修改为随机字符串** |

可选：`SEMANTIC_SCHOLAR_API_KEY` 可提高文献检索速率；`ADMIN_PASSWORD` 可修改默认管理员密码。

### 2. 安装并启动

```bash
# 安装后端依赖
pip install -r requirements.txt

# 安装前端依赖
cd frontend && npm install && cd ..

# 终端 1：启动后端（http://localhost:8000）
python run.py

# 终端 2：启动前端（http://localhost:3000）
cd frontend && npm run dev
```

浏览器访问 **http://localhost:3000** 即可使用。

### 3. 登录

首次启动会自动创建管理员账号：

| 用户名 | 密码 |
|--------|------|
| `admin` | `.env` 中的 `ADMIN_PASSWORD`（默认 `admin123`） |

也可在登录页注册新账号。每个用户的数据相互独立。

### 4. 生产部署（可选）

构建前端后，只需启动后端即可同时提供 Web 界面：

```bash
cd frontend && npm run build && cd ..
python run.py
```

部署前请修改 `JWT_SECRET` 与 `ADMIN_PASSWORD`。

## 使用指南

### 创建一份工作方案

1. 登录后进入 **工作台**
2. 选择场景类型（文献综述 / 实验方案 / 完整方案）
3. 勾选本次需要参与协作的 Agent 角色（取消某角色将跳过其对应任务）
4. 在文本框中详细描述研究课题：背景、目标、约束条件等
5. （可选）上传参考文件，补充课题背景或已有资料
6. 点击 **开始执行**，进入工作流页面实时查看进度

### 工作流进行中

- 各 Agent 的输出会**逐段流式显示**，工具调用（文献检索、文件解析、计算等）状态同步展示
- 遇到需人工审核的节点，页面会出现**审核面板**：可填写修改意见，选择批准继续或驳回终止
- 运行中可随时 **中止**；之后可从断点 **继续** 执行
- 完成后可直接 **导出 Markdown 或 Word**

### 管理 Agent 角色

进入 **Agent 角色** 页面，可以：

- 查看五个内置角色的职责说明
- 新建自定义角色（名称、背景、目标、可用工具、是否启用推理模式）
- 编辑或删除自己创建的自定义角色

自定义角色创建后，可在工作台中与其他内置角色一起勾选使用。

### 查看历史方案

进入 **历史方案** 页面：

- 列表展示每次生成方案的**标题**、场景、任务数与创建时间
- 顶部**搜索框**支持按标题或需求描述检索
- 点击任意记录查看完整方案内容与各任务输出
- 支持导出为 Markdown 或 Word

> 标题默认取自你输入需求的第一行；若同一用户下标题重复，系统会自动追加时间戳以区分。

## 三种场景说明

| 场景 | 适用情况 | 协作流程 |
|------|----------|----------|
| **文献综述生成** | 需要梳理领域文献、形成综述框架 | 课题规划 → 文献调研 → 方案终审 |
| **实验方案设计** | 已有方向，需设计实验方法与预算 | 课题规划 → 实验设计 → 预算编制 → 方案终审 |
| **完整工作方案** | 从零到完整方案的一站式制定 | 五个 Agent 全流程协作 |

## 内置 Agent 角色

| 角色 | 职责 |
|------|------|
| **课题规划师** | 分析需求，梳理研究框架与关键问题 |
| **文献调研专家** | 检索学术文献（Semantic Scholar / PubMed），整理综述要点 |
| **实验方案设计师** | 设计实验方法、对照组、样本量等（启用推理增强） |
| **预算资源分析师** | 估算人力、设备、试剂等资源与预算 |
| **方案终审专家** | 整合各阶段成果，做质量评审与最终定稿 |

## 常见问题

**Q：服务重启后进行中的工作流还在吗？**  
A：进行中的任务保存在内存中，重启后会丢失；**已完成的方案**会持久保存，可在历史方案中查看。

**Q：文献检索需要什么额外配置？**  
A：默认可用 Semantic Scholar 与 PubMed；配置 `SEMANTIC_SCHOLAR_API_KEY` 可提高检索速率。

**Q：支持哪些参考文件格式？**  
A：txt、md、csv、json，单文件不超过 2MB。

**Q：数据存在哪里？**  
A：默认在 `data/` 目录（数据库、上传文件、历史方案）。建议定期备份该目录。

**Q：API 文档在哪里？**  
A：后端启动后访问 http://localhost:8000/docs 查看 Swagger 交互文档（需登录令牌）。
